# Portafolio — Jorge Magzul

Portafolio digital de desarrollador de software (web & mobile), construido con **React 19** y **Vite**.

🔗 **Sitio en vivo:** _agrega aquí tu enlace de Vercel_

## Secciones
Inicio · Sobre mí · Habilidades · Experiencia · Proyectos · Contacto

## Ejecutar en local
```bash
git clone https://github.com/jmagzul-2024029/Portafolio.git
cd Portafolio
npm install
npm run dev
```
Otros scripts: `npm run build`, `npm run preview`, `npm run lint`.

## Estructura
```
src/
├── components/   Header, Footer, ProjectCard, Galaxy (fondo WebGL)
├── sections/     Hero, About, Skills, Experience, Projects, Contact
└── App.jsx
```

## Personalizar
- Proyectos: `src/sections/Projects.jsx`
- Habilidades: `src/sections/Skills.jsx`
- CV: coloca tu archivo en `public/cv.pdf`
